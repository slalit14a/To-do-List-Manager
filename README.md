# 📝 To-Do List Manager

A simple and efficient command-line To-Do List Manager built using Python. This application helps users organize their daily tasks by allowing them to add, view, delete, and mark tasks as completed. The project is designed for beginners who want to learn Python programming through a practical real-world application.

## 🚀 Features

* Add new tasks
* View all saved tasks
* Delete unwanted tasks
* Mark tasks as completed
* Store tasks permanently in a text file
* Simple and user-friendly menu system
* Error handling for invalid inputs

## 🛠️ Technologies Used

* Python 3
* File Handling
* Lists
* Functions
* Loops
* Conditional Statements
* Exception Handling

## 📂 Project Description

The To-Do List Manager is a productivity application that helps users keep track of their daily activities. All tasks are saved in a text file (`tasks.txt`), ensuring that task data is not lost when the program is closed. Users can easily manage their tasks through a menu-driven interface.

This project demonstrates important Python concepts such as reading and writing files, working with lists, creating reusable functions, handling user input, and implementing basic CRUD (Create, Read, Update, Delete) operations.

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```
